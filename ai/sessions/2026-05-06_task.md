## 問題と原因
- CamillaDSP の Conv フィルタ（Wav）で未サポートのパラメータを設定していた
  - 原因: resampler_type / interpolation を Conv 側で指定していたが、公式仕様外
- 48kHz IR を 192kHz パイプラインへそのまま投入していた
  - 原因: IR 側のサンプルレート整合処理が不足
  - 影響: 残響時間・周波数特性の不正（意図しない音）
- DSP 失敗時に split/mix が残る可能性があった
  - 原因: 例外経路で mixer/pipeline のクリーンアップ不足
- エラー時でも 200 応答になる API があり、フロントで失敗検知しにくかった
  - 原因: JSON の status=error のみで HTTP ステータス未設定
- USB 判定が device 文字列依存で不安定だった
  - 原因: USB の判定にカード番号照合を使っていなかった
- 起動時設定復元の失敗が無ログで追跡不能だった
  - 原因: 例外を pass のみで握りつぶしていた

## 変更前（Before）
- Conv フィルタに仕様外パラメータを指定
- 48kHz IR をそのまま使用
- IR 処理失敗時に pipeline/mixer の残骸が残る可能性
- API 失敗時の HTTP ステータスが曖昧
- USB 判定が device 文字列依存
- 起動時復元失敗のログなし

## 変更後（After）

# Conv（Wav）は仕様に沿って最小構成へ
add_f_wet("rev", {
  "type": "Conv",
  "parameters": {
    "type": "Wav",
    "filename": src_ir
  }
})

# IR は適用前に 192kHz へ正規化（既に 192kHz ならスキップ）
_ensure_ir_192k(src_ir, target_rate=192000)

# IR 処理例外時は split/mix を確実に除去して reverb 無効化
y["pipeline"] = [p for p in y["pipeline"] if not (p.get("type") == "Mixer" and p.get("name") in ("split", "mix"))]
y["mixers"].pop("split", None)
y["mixers"].pop("mix", None)
config.reverb = "none"

# USB 判定は ALSA カード番号で照合
selected_card = _extract_alsa_card_number(config.device)
is_usb = bool(usb_card and selected_card and selected_card == usb_card)

# API エラー時は HTTP ステータスを返す
