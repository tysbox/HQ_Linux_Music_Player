# A（音質改善）の計測操作 — 具体的手順

必要な機器
- 測定用マイク（USB接続のコンデンサマイク推奨、例: UMIK-1）
- マイクスタンド（スピーカーと同じ高さに設置）
- PC（このアプリが動作しているものと同じ）

操作手順（概算時間: 2〜4時間）

1. 部屋の準備（30分）
   - 窓を閉め、エアコンを停止（ノイズ低減）
   - スピーカーを通常の聴取位置に配置

2. マイク設置（15分）
   - スピーカーから1m離れた位置、耳の高さにマイクを設置
   - マイクをPCに接続

3. IR（インパルス応答）測定（1〜2時間）
   - 測定ソフト（REW: Room EQ Wizard など無料）を起動
   - スピーカーからテスト信号（スイープ音）を再生
   - マイクで録音 → 部屋の音響特性（反射、吸収）が数値化される
   - 複数位置（左、中央、右）で繰り返し測定

4. データ解析（30分〜1時間）
   - 測定結果をグラフ化（周波数特性、残響時間 RT60）
   - 現在のHPF（80Hz）/LPF（5kHz）の設定が適切か判断
   - 必要に応じて数値を調整（例: 部屋が低音を強調するならHPFを上げる）

5. 設定反映（15分）
   - 調整した数値を `backend/main.py` の `generate_camilladsp_yaml()` に反映
   - `/api/apply` でDSPを再起動
   - 聴感テスト（実際に音楽を再生して確認）

デメリットの詳細
- マイク購入費用（1〜3万円程度）が必要
- 測定中は静かな環境が必要（家族の協力が必要な場合あり）
- 数値調整は試行錯誤が必要（1回で完璧にはならない）

効果の目安
- 適切に調整すると、音の濁りが減り、楽器の位置が明確になる
- ただし、劇的な変化ではなく「自然になる」程度（過度な期待は禁物）
